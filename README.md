# PostgresPro 1C-17 Docker

Этот проект предоставляет Docker-образ для развертывания СУБД PostgresPro 1C-17 в изолированном окружении. Образ оптимизирован для работы с платформой 1С:Предприятие и включает все необходимые настройки для оптимальной производительности.

## Требования

- Docker версии 20.10+
- Docker Compose версии 1.29+
- Минимум 2 ГБ свободной оперативной памяти
- Минимум 10 ГБ свободного места на диске

## Быстрый старт

### Запуск с использованием Docker Compose (рекомендуется)

1. Клонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   cd <директория-репозитория>
   ```

2. Настройте переменные окружения (опционально):
   ```bash
   cp .env.example .env
   # Отредактируйте .env файл под свои нужды
   ```

3. Запустите контейнер:
   ```bash
   docker-compose up -d
   ```

### Запуск с использованием Docker

1. Соберите образ:
   ```bash
   docker build -t postgrespro-1c-17:latest .
   ```

2. Запустите контейнер:
   ```bash
   docker run -d \
     --name postgrespro-1c \
     --restart unless-stopped \
     -e POSTGRES_PASSWORD=mysecretpassword \
     -e POSTGRES_DB=my1cdb \
     -v pgdata:/var/lib/pgpro/1c-17/data \
     -v ./config:/etc/pgpro/1c-17 \
     -p 5432:5432 \
     postgrespro-1c-17:latest
   ```

## Переменные окружения

| Переменная              | Значение по умолчанию | Описание                  |
|-------------------------|-----------------------|---------------------------|
| `POSTGRES_USER`         | `postgres`            | Суперпользователь БД      |
| `POSTGRES_PASSWORD`     | *Обязательно*         | Пароль суперпользователя  |
| `POSTGRES_DB`           | `postgres`            | Имя базы данных           |
| `POSTGRES_INITDB_ARGS`  | `--encoding=UTF8`     | Аргументы инициализации   |
| `PGPRO_1C_MEMORY`       | `1GB`                 | Ограничение памяти        |

## Тома данных

- `pgdata`: Основной том для хранения данных БД
- `./config`: Том для пользовательских конфигураций
- `./backup`: Том для резервных копий (опционально)

## Подключение к базе данных

```bash
# Из другого контейнера
psql -h postgrespro-1c -U postgres -d my1cdb

# С хост-машины
psql -h localhost -U postgres -d my1cdb
```

## Мониторинг и обслуживание

### Проверка состояния
```bash
docker ps
docker logs postgrespro-1c
```

### Резервное копирование
```bash
docker exec postgrespro-1c pg_dump -U postgres my1cdb > backup.sql
```

### Восстановление из резервной копии
```bash
docker exec -i postgrespro-1c psql -U postgres my1cdb < backup.sql
```

## Оптимизация производительности

Образ настроен с оптимальными параметрами для работы с 1С:
- Настроен shared_buffers
- Оптимизированы параметры WAL
- Настроены параметры для работы с большими объемами данных

## Безопасность

- Используйте сложные пароли
- Ограничьте доступ к порту 5432 только необходимыми IP-адресами
- Регулярно обновляйте образ
- Используйте отдельного пользователя для приложений 1С

## Устранение неполадок

1. Проверка доступности порта:
   ```bash
   telnet localhost 5432
   ```

2. Проверка логов:
   ```bash
   docker logs postgrespro-1c
   ```

3. Проверка использования ресурсов:
   ```bash
   docker stats postgrespro-1c
   ```

## Лицензирование

PostgresPro 1C-17 требует действующей лицензии. Убедитесь, что у вас есть все необходимые лицензии перед использованием в продакшене.

- При обновлении образа проверяйте совместимость с вашей версией 1С
