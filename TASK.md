# Техническое задание на создание Docker-контейнера с PostgresPro 1C-17

## 1. Введение
**Цель:** Создать Docker-образ для развертывания СУБД PostgresPro 1C-17 в изолированном окружении.  
**Область действия:** Контейнер должен обеспечивать автоматическую инициализацию БД, настройку через переменные окружения и хранение данных на внешних томах.

---

## 2. Описание задачи
Разработать Docker-контейнер на базе ОС Ubuntu, включающий:
- Установку PostgresPro 1C-17 из официального репозитория.
- Автоматическую инициализацию БД.
- Настройку через переменные окружения (пароль, пользователь, БД).
- Сохранение данных на внешних томах (Volumes).

---

## 3. Требования к окружению
- **Docker версии 20.10+**
- **ОС хоста:** Любая, поддерживающая Docker (Linux, Windows, macOS).

---

## 4. Спецификация Docker-образа

### 4.1. Базовый образ
- **Исходный образ:** `ubuntu:22.04`

### 4.2. Установка зависимостей
- Установка пакетов: `wget`, `apt-utils`.

### 4.3. Добавление репозитория PostgresPro
- Загрузка скрипта:  
  ```bash
  wget https://repo.postgrespro.ru/1c/1c-17/keys/pgpro-repo-add.sh
  ```
- Выполнение скрипта:  
  ```bash
  sh pgpro-repo-add.sh
  ```

### 4.4. Установка пакета
- Установка:  
  ```bash
  apt-get install -y postgrespro-1c-17-contrib
  ```

### 4.5. Инициализация БД
- Создание каталога данных:  
  ```bash
  mkdir -p /var/lib/pgpro/1c-17/data
  ```
- Инициализация:  
  ```bash
  /opt/pgpro/1c-17/bin/pg-setup initdb -D /var/lib/pgpro/1c-17/data
  ```

### 4.6. Настройка конфигурации
- **postgresql.conf:**  
  ```bash
  echo "listen_addresses = '*'" >> /var/lib/pgpro/1c-17/data/postgresql.conf
  ```
- **pg_hba.conf:**  
  ```bash
  echo "host all all all scram-sha-256" >> /var/lib/pgpro/1c-17/data/pg_hba.conf
  ```

### 4.7. Открытие порта
- **Порт:** `5432`

### 4.8. Volume для данных
- **Точка монтирования:** `/var/lib/pgpro/1c-17/data`

### 4.9. Скрипт запуска
- **Entrypoint:** Скрипт `/docker-entrypoint.sh` выполняет:
  1. Проверку инициализации БД.
  2. Настройку пользователя и пароля через переменные окружения.
  3. Запуск сервера PostgresPro.

---

## 5. Переменные окружения
| Переменная              | Значение по умолчанию | Описание                  |
|-------------------------|-----------------------|---------------------------|
| `POSTGRES_USER`         | `postgres`            | Суперпользователь БД.     |
| `POSTGRES_PASSWORD`     | *Обязательно*         | Пароль суперпользователя. |
| `POSTGRES_DB`           | `postgres`            | Имя базы данных.          |

---

## 6. Инструкция по сборке и запуску

### Сборка образа
```bash
docker build -t postgrespro-1c-17:latest .
```

### Запуск контейнера
```bash
docker run -d \
  --name postgrespro-1c \
  -e POSTGRES_PASSWORD=mysecretpassword \
  -v pgdata:/var/lib/pgpro/1c-17/data \
  -p 5432:5432 \
  postgrespro-1c-17:latest
```

---

## 7. Тестирование
1. Проверка доступности порта:  
   ```bash
   telnet localhost 5432
   ```
2. Подключение к БД:  
   ```bash
   psql -U postgres -h localhost
   ```

---

## 8. Примечания
- Данные БД сохраняются в Docker-томе `pgdata`.
- Для кастомизации конфигурации используйте файлы в `/var/lib/pgpro/1c-17/data`.
- Скрипт `pg-setup service` не используется из-за отсутствия systemd в контейнере.
